## Futon 9.8.3

This release focuses on reliable Mihon/Keiyoushi extension compatibility and the complete runtime path from extension loading to browsing, chapters and pages.

### Highlights

- Updated the Futon host ABI for current Mihon/Keiyoushi extensions, including the modern suspend `Source` and `HttpSource` APIs while retaining compatibility with older Rx-based extensions.
- Added durable Mihon manga and chapter snapshots so extension-provided metadata survives repository recreation and app process restarts.
- Added the Kototoro-style Tachiyomi APK classloader ownership policy for stable host ABI resolution.
- Release APKs use the repository release signing key and are verified before publication.

### Compatibility fixes

- Fixed the required Mihon default OkHttp interceptor contract and ordering.
- Added host-visible Brotli and Zstd runtime support required by dynamically loaded extensions.
- Fixed serializer/default-method ABI failures by aligning the host baseline to Android API 26.
- Added `SManga.memo`, `SChapter.memo`, `SMangaUpdate`, `Source.getMangaUpdate(...)`, current request context support and modern chapter/page APIs.
- Preserved complete chapter metadata across repository instances and across app restarts.
- Fixed restore ordering where modern model setters could overwrite independently persisted legacy fields.
- Improved extension repository isolation, metadata/version handling and source preference compatibility.
- Retained Cloudflare WebView solving with clearance detection and retry of the original source request.

### Validation

The release candidate passed the focused Mihon regression suite, release lint, optimized R8 build, runtime ABI inspection and APK signature verification. The repository-key release candidate was also validated successfully on real Android hardware.

### Upgrade notes

- Minimum supported Android API is now 26 because current Mihon/Keiyoushi extension runtime compatibility depends on that baseline.
- The release is signed with the long-lived Futon repository release key.
